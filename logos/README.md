# CloudTrio logo package

A hexagon badge holding a cloud with a T cut out of it, and three circuit traces below it
(cloud, tech, and the "trio"). Wordmark: **Cloud** + **Trio**, tagline `CLOUD · TECH · AI`.

| Colour | Hex | Use |
|---|---|---|
| Navy | `#14295c` | "Cloud" on light backgrounds, mono logo |
| Teal | `#12a89d` (light bg) / `#2fd4c4` (dark bg) | "Trio", circuit traces |
| Deep navy | `#091a36` | badge fill, dark backgrounds |
| Rim gradient | `#2fe0cf` > `#1a8fd8` > `#1b3f9a` | badge outline |

Font: Sora ExtraBold (wordmark), DM Sans Medium (tagline), both from Google Fonts.

## Files

`svg/` is the editable source, `png/` is rendered from it (transparent unless noted).

| File | Size | Use |
|---|---|---|
| `cloudtrio-mark` | 1024 | The badge alone, full colour. Works on light and dark. |
| `cloudtrio-mark-mono-navy` / `-white` | 1024 | One-colour badge for stamps, print, watermarks. |
| `cloudtrio-lockup-light` | 2120x560 | Badge + wordmark for white / light backgrounds. |
| `cloudtrio-lockup-dark` | 2120x560 | Badge + wordmark for dark backgrounds. |
| `cloudtrio-lockup-mono-navy` / `-white` | 2120x560 | One-colour lockups. |
| `cloudtrio-profile` | 1080 | Instagram / social profile picture (not transparent; platforms crop it to a circle). |
| `cloudtrio-icon` | 512 | App icon: badge on a rounded dark tile. |
| `cloudtrio-banner` | 1500x500 | X / LinkedIn / Facebook cover (not transparent). |
| `favicon.ico`, `png/favicon-16..512.png` | 16 to 512 | Website favicons; use 180 for the Apple touch icon, 192 / 512 for the web manifest. |

The lockup SVGs use live text, so they show Sora only when the font is installed or online;
use the PNGs when you need the exact look.

## Rules

- Keep clear space around the badge of at least a quarter of its width.
- Minimum size: 24 px for the badge, 120 px wide for the lockup.
- Do not recolour, stretch, rotate or add effects.
