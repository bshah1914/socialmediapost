                  Backups

                  A copy of the database is kept on the server's disk (free) and opened right after to check it is complete. To move from the SQLite file to PostgreSQL, an admin runs flask --app run migrate-db --to postgresql://… on the server and sets DATABASE_URL.

                    Copy away from this server

                    A copy on the same disk does not survive the disk. Each backup (and the Instagram login) can also go to an online bucket and/or a folder on another machine. It is scrambled with the secrets key first, so the bucket shows nothing readable. Cloudflare R2 and Backblaze B2 both have a free tier.

                    Is the site up?

                    Every 5 minutes the newsroom opens its own public address. Two misses in a row send an alert, and another when it is back. To also hear about the whole server being off, make a free check at healthchecks.io (or UptimeRobot heartbeat), paste its ping address here, and set that service to email or message you when the pings stop.

                    Sign in with Google

                    Lets people sign in with their Google account. They still need an account here: set the Google email on their row under Team and roles. Nobody is added by signing in. Create the client in Google Cloud Console, Credentials, OAuth client ID, Web application, with this redirect address:

                    Protected secrets

                    Passwords and tokens are stored scrambled, and the key is kept outside the data folder, so a copy of the data or a backup cannot reveal them.
